02原则

六条，每条都能落成检查项。

#原则为什么
1容器定尺寸，页面不定。一致性不来自令牌，来自容器。SearchField 已经是全 App 唯一实现，它照样比邻居高 7pt——因为没有东西规定它跟谁并排。
2一行一档，一行一字号。同一条水平线上的控件必须同高、同字号。
3基线优先于框。两段不同字号的中文要看起来在一条线上，对齐的是基线，不是框中心。
4响度对应后果。越不可逆的动作，视觉越安静。最响的实心色块留给「让用户变好的那件事」。
5数字是内容。这是一个量东西的 App。等宽数位、数值与单位分离、列右对齐、精度分档。
6可以量。每条规则都有数字，改完用探针量，量不到就不算改完。

05破坏性与可逆性的视觉语法

README 第一段承诺「破坏性按钮不是最显眼的那个」，而代码让它成了最显眼的那个。 加一个 tint: 参数修不好这件事，因为参数就是邀请。 现在调用方声明的是意图，形态与颜色由意图推导，选不了颜色。

意图形态样例（真实尺寸）对比度
go
可逆 · 好事		 实心 goFill，配 onAccent。唯一能实心的意图 ✦ 开始清理 4.64:1
neutral
无后果		 玻璃胶囊 + 描边，ink 字 ↻ 重新扫描 16.6:1
reversible

destructive
不可逆 · 提议		 描边 danger + 6% 底。列表与工具条里永不实心 🗑 卸载所选 2 4.53:1
confirm
不可逆 · 确认		 实心 dangerSolid，白字。仅确认界面 永久删除 5.57:1

两条硬规则

其一 · 实心只给「可逆的好事」。实心填充是页面上最响的东西，只用于让用户变好、且做错了能撤回的动作。 其二 · 实心 danger 只活在确认里。一个界面最多一个实心色块。 .confirm 画在没有 confirmationSurface() 标记的地方时，会退化成普通的描边破坏性按钮—— 这不是约定，是类型系统里的事实。

可逆的删除不该染红

「移到废纸篓」以前用的是 danger。把可还原的动作染成红色，等于教用户忽略红色—— 真正不可逆的地方就没有词可用了。同理，它应该常显，不该藏在悬停里。

06对比度：标准自己错了一处

标准 §4.2 写着「实心 aquaSweep，白字，白 / aqua = 4.9:1 ✓」。 用调色板里的实际色值算，这一行是错的——而且错得比它要修的问题还严重。

组合实测结果
白字 / aquaBright #11B3A4（浅色渐变起点）2.62:1不达标
白字 / aqua #0B8F84（浅色中点）3.98:1不达标
白字 / aquaBright #62F0DA（深色起点）1.40:1几乎看不见
对照：白字 / 12% danger 玻璃 tint（被拿来当反面教材的那颗）1.39:1—
白字 / goFill 浅色最差档4.64:1达标
近黑 / goFill 深色最差档5.68:1达标
白字 / dangerSolid 浅 #C0342F5.57:1达标
白字 / dangerSolid 深 #8F2C288.21:1达标

也就是说「开始清理」——全 App 最响、最该被看清的那颗按钮——比标准专门写来修的那颗还难读，深色下尤其糟。 渐变承载不了文字。

改法

aquaSweep 降级为纯装饰（水位环、容量条、树图，都不承载文字），另立两个成对的令牌： goFill 浅色走深、深色保持亮薄荷；onAccent 浅色白、深色近黑。 这一个前景色令牌覆盖全部强调色的场合——这套调色板的所有强调色在浅色下都偏深、在深色下都偏亮， 所以「压在强调色上的字」的颜色是跟着外观翻转的。

浅色深底 + 白字
✦ 开始清理 ✦ 旧：2.62:1
同一个动作，右边是 0.3.6 的画法
深色亮底 + 近黑字
✦ 开始清理 ✦ 旧：1.40:1
深色下保留品牌的亮薄荷，翻转的是字色

玻璃控件的最小可辨度

在浅色「深水」地上，.ultraThinMaterial 加 0.5pt 描边几乎看不出边界—— 「看看有哪些」的边缘基本消失了。现在任何可点的玻璃控件都带一层足够不透明的填充加至少 16% 的描边， macOS 26 与回退分支都画。非交互的玻璃面板可以更透。

两处第一轮没量对，改了

  1. 侧栏品牌 x = 32，不是 24。侧栏面板本身被系统内缩了 8，所以 24 的内边距把品牌推到了 32，而导航项在 24。改成 16。
  2. 行标题左边线 = 80，不是 72。复选框的命中区是 24 宽，把后面所有东西推了 8。改成横向 16（纵向仍是一个控件档）。

已知偏差

紧凑表格行用 8pt 内缩的自有几何，不遵守 72 的标题左边线（标准里本就分开定义）。 默认 1200 窗口下四张统计卡仍是 2×2，这是网格的既定行为。 这台机器无法截图核对像素，视觉部分靠两条可计算的证据：探针量出的几何，和上面算出的对比度。
