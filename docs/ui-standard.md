# MacPleco 界面标准（UI Standard）

> 版本 1.0 · 2026-09-07 · 基于 0.3.6（`5f511c5`）的全量盘点与实测。
> 这份文档回答三个问题：**现在有什么、哪里不一致、以后怎么做**。
> 前两部分是证据，第三部分是规则。所有规则都有数字，可以用探针验证（见附录）。

---

## 0. 怎么用这份文档

- **每个页面都从骨架继承**（§3.2）：标题行、说明行、内容块，顺序、缩进、间距不由页面决定。
- **需要一个控件时先查档位表**（§3.4）：同一行里的控件必须同一档；只允许 24 / 32 / 44 三种高度。
- **需要一段文字时先查角色表**（§3.3）：页面代码不允许自己拼字号、字重、字体设计。
- **需要一块颜色时先查语义表**（§3.5）：颜色说明"是什么"，不说明"好不好看"。
- 页面里出现了表里没有的东西，先在 `Design/` 里加组件或角色，再在页面里使用。**页面不产生新样式。**

#### H. 文字

字阶 `Typo` 有 11 级、15 个具名角色，但实际使用中：

| 用法 | 次数 |
|---|---|
| 引用具名角色 `Typo.xxx` | 104 |
| 用 `Typo.Step.xxx` 自行拼装字重 / 字体设计 | 108（共 40 种组合） |
| 直接写数字 | 6 处（`SafetyChip` 8 / 9，`LeftoverRow` 9.5 / 10 / 11 / 12） |

也就是说一半以上的文字绕过了角色。同一个意思在不同页面被拼成不同样子：行标题在应用页是 13 semibold，在优化页是 13 semibold（另一种写法），在类别头是 15 semibold，在进程行是 12 regular，在登录项是 12 medium。

## 2. 原则

六条，每条都能落成检查项。

1. **一行一档。** 同一行、同一容器里的控件用同一个尺寸档（§3.4）。不同档的东西不放在一条水平线上。
2. **只有三种高度。** 可点的东西高 24、32 或 44，没有第四种。内边距从 4pt 网格取，不做加减法。
3. **角色，不是样式。** 文字只能引用 `Typo` 角色，颜色只能引用 `Palette` 语义名，圆角只能引用 `Radius`。页面文件里不出现数字。
4. **一种东西一个组件。** 徽章、按钮、筛选行、行卡、报头各有唯一实现；页面只选参数，不改外观。
5. **骨架先于内容。** 每页都是：报头行 → 说明行 → 内容块。位置、缩进、间距由骨架决定，页面只填内容。
6. **可以量。** 每条规则都有数字；改完用探针量，量不到就不算改完。

## 3. 标准

### 3.1 令牌

#### 网格与间距 `Space`

保留现有八级：2 / 4 / 8 / 12 / 16 / 24 / 32 / 48。规则：

- 控件内边距、行间距、块间距只能取这八个值。**禁止 `Space.sm + 2`、`Space.lg + Space.xs` 这类算术**（现有 6 处）。
- 固定用途：块间距 16（`Page` 已用）；列表行间距 8；栅格列距 12；卡内元素间距 8 / 12；内容列四周 32。

#### 圆角 `Radius`

| 令牌 | 值 | 用途 |
|---|---|---|
| `pill` | 999 | 按钮、搜索框、徽章 |
| `panel` | 22 | 页面级大卡：英雄卡、摘要卡、地图卡、类别卡 |
| `card` | 16 | 统计卡、**所有行卡**（应用、登录项、大文件、前 12、**任务卡改为 16**）、横幅 |
| `row` | 12 | 条形容器：选择条、面包屑栏、侧栏底栏、菜单栏面板内的井 |
| `chip` | 8 | 图标盒 32、行内悬停底、小井 |
| `control` | 4 | 新增：复选框、图例方块、核心条、树图瓦片以外的小方块 |

嵌套规则：子圆角 = 父圆角 − 父内边距（22 − 12 ≈ 8 → 地图卡内的地图用 `card` 16 是特例，保留）。树图瓦片圆角 7 → 改 8（`chip`）。**删除源码中所有圆角字面量。**

#### 控件高度 `Control`（新增）

| 档 | 高 | 用途 |
|---|---|---|
| `Control.large` | 44 | 页面唯一的号召动作 |
| `Control.medium` | 32 | 条、卡片、sheet 里的动作 |
| `Control.small` | 24 | 筛选行、行内动作、报头插槽 |

所有按钮、输入、选择控件的高度只能是这三个值。系统控件通过 `controlSize` 对齐：`.regular` = 24（分段、下拉、`.small` 开关本体 18 居中于 24）。

#### 图标（字形）尺寸 `Glyph`（新增，替代页面里的 `Typo.Step.x` 当图标用）

| 名 | 值 | 用途 |
|---|---|---|
| `badge` | 9 | 徽章内、排序箭头、结果行 |
| `caption` | 11 | 说明行、统计卡头、行内图标按钮 |
| `control` | 12 | 搜索、S 档按钮内 |
| `row` | 15 | 行卡主图标、M 档按钮内、类别图标盒内 |
| `card` | 17 | 扫描卡、战绩条 |
| `title` | 20 | 权限卡、sheet 头 |
| `feature` | 30 | 空态、不可读态 |

图标盒（有底色的方形）只有三种：**24（圆角 6）、32（圆角 8）、44（圆角 12）**。类别 34 → 32；占用横幅 30 → 32；品牌 30 / 32 / 22 → 主窗口 32、设置 32、菜单栏 24。

### 3.2 布局

#### 窗口

- 最小 980×660，默认 1200×800，不变。
- 内容列最大 1140，左右各 32，不变。

#### 报头行（Masthead，新）

侧栏和内容列共享**同一条报头行**：从标题栏下缘起 12pt，高 32。两列的东西都在这条 32 高的带子里**垂直居中**。

| 列 | 内容 | 位置（标题栏下缘 = 0） |
|---|---|---|
| 侧栏 | 图标盒 32（圆角 8）+ "MacPleco" 17 bold rounded | 图标 y 12–44；文字框 y 18–38；**中心 28** |
| 内容列 | 页面标题 20 bold rounded | 框 y 16–40；**中心 28** |
| 内容列右侧 | 插槽：只放 **S 档（24）** 控件 | y 16–40；**中心 28** |
| 内容列 | 副标题 13 secondary | 报头行下 4：y 48–64 |
| 内容列 | 说明行 `PageNote` 11 | 副标题下 8；固定 16 高；若带按钮，按钮也是 S 档 24，行高 24 |
| 内容列 | 第一个内容块 | 标题组下 24（= 组内 8 + 块距 16，与现在一致） |

换算成 `Page`：上边距从 24 改为 **16**（标题框 24 高居中于 32 的带子需要上留 4，12 + 4 = 16）；标题 `Text` 外包 `.frame(height: 32)` 居中；侧栏品牌行上边距 12 不变、图标改 32、左右内边距改 **24**（与导航项标签同一条左边线，P11）。

右侧插槽：分段控件（24）直接放；"重新扫描 / 重新查找 / 打开登录项设置"改 **S 档幽灵按钮**（24）。插槽高度恒为 24，说明行高度不再随内容变化（P10）。

#### 侧栏

- 品牌行、导航项、底栏的左边线都是 **24**。
- 导航项由系统绘制，不动。
- 底栏是"井"（`wellFill`，圆角 12，内边距 12），左右外边距 12，下 12，不变。

#### 内容块

- 块间距 16；同一块内的行间距 8；栅格列距 12。
- 条（选择条、面包屑栏）：圆角 12，左右 12，**高度由档位决定**：含 M 档按钮 = 48，只有文字与 S 档 = 40。
- 统计卡网格：所有网格一个最小宽 **224**，列数规则不变（尽量整除）。**明确：内容列 ≤ 908 时四张卡为 2×2，≥ 920 时 4×1。** 默认 1200 窗口是 2×2，这是预期。

#### 页面模板

| 模板 | 页面 | 块序 |
|---|---|---|
| 仪表页 | 概览、监控 | 报头 → [英雄卡 或 仪表网格] → 统计网格 / 信息条 → 列表卡 → 脚注 |
| 列表页 | 清理、应用、优化、空间·大文件 | 报头 → (说明行) → 筛选行(S) → 选择条(M) → 行列表 → (脚注) |
| 地图页 | 空间·地图 | 报头 → 说明行 → 面包屑栏 → 地图卡 → 卡片栅格 → (脚注) |

清理页的摘要卡是列表页的"英雄卡"变体：它替代筛选行与选择条的位置，里面的主按钮是 L 档。

### 3.5 语义色

`Palette` 不动，把"谁用哪种颜色"定死：

| 颜色 | 意义 | 允许出现的地方 |
|---|---|---|
| `ink` | 主文字 | 标题、行标题、数值 |
| `inkSecondary` | 支持句 | 副标题、说明句、说明行 |
| `inkTertiary` | 标签与元数据 | `SectionLabel`、统计卡标签、时间、版本、弱文字按钮 |
| `inkFaint` | 存在即可 | 路径、PID、占位、未选中描边 |
| `aqua` | **品牌 + 安全 + 选中** | Primary 默认 tint；`safe` 芯片；选中态填充与描边；进度默认色；品牌图标 |
| `flow` | **可以点的文字 + 信息** | Tertiary 按钮、链接、面包屑、活动表头、行内"访达"图标、权限卡 tint |

| `danger` | 破坏性 / 不可恢复 | 卸载类 Primary / Secondary；`careful` 芯片；"跳过废纸篓"开关；结束进程图标 |
| `positive` | 已完成的好结果 | 优化成功行、权限已授予、温度正常徽章 |
| `chart*` / `folderTones` / `fileTone` / `tailTone` | 只在图表和图例里 | 监控、空间 |

填充不透明度只有四档：**井 5%（`wellFill`）· 悬停 6% · 选中 8% · 徽章与图标盒 14%**（卡片 tint 12% 保留为第五档，仅 `GlassCard`）。

## 附录 A · 怎么量

复制模块到临时目录，在要量的视图上加一个 `measure("名字")` 修饰符（`onGeometryChange` 读 `.global` 坐标），用一个 `@main` 探针把 `RootView().environment(AppModel())` 装进 `NSHostingView`（`sceneBridgingOptions = [.all]` 才有系统工具栏），逐页切 `model.destination`，等数据到了再打印。整个模块用 `swiftc -parse-as-library -Onone` 单次编译约 12 秒；一轮八个页面约 70 秒。要点：

- 在真实窗口里量，不要另搭裸组件——内容（尤其中文）才是把布局撑坏的东西。
- `.rises()` 的入场位移会让同一个视图出现两个坐标，取小的那个。
- 网格列数依赖容器宽，1200 和 1600 各量一次。
- 截图工具在这台机器上不可用，Accessibility 也未对 shell 授权；坐标只能从进程内部读。
